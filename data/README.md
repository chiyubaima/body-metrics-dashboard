# Public food catalog

foods.json is a compact, server-only projection of USDA FoodData Central's CC0 datasets: SR Legacy (2018-04, final) and FNDDS 2021–2023 (2024-10-31 release). Retrieved 2026-09-07 from https://fdc.nal.usda.gov/download-datasets/ . This is not the complete FDC branded-food database.

Each row: [fdcId, original description, dataset version, kcal, protein grams, carbohydrate grams, fat grams], all per 100g edible portion. Missing nutrients remain null. Energy prefers USDA nutrient 1008; then 2048/2047. No model-generated nutrient values.

Rebuild the original data: `python3 scripts/build-food-catalog.py`. Raw archives go in work/ and may be removed after catalog verification. The script never reads user records. These are editorial Chinese translations, not official USDA translations; they do not establish equivalence between Chinese dishes and US recipes. Original English descriptions and stable FDC IDs accompany results and saved records. The client receives only one result page; personal meal weights are stored in D1 as before.

Full-catalog Chinese revision, 2026-09-08: `food-translations.json` contains all 13,225 FDC IDs (13,143 distinct descriptions). `food-translation-glossary.json` contains the editorial phrase dictionary; `lib/food-labels.ts` supplies the earlier shared terms and fallback for foods outside this catalog. `scripts/build-food-translations.mjs` combines these with context rules for meat, dairy, eggs and bread. Bread head-name rewriting only applies at the start of a food name, so a list of bread and cheese ingredients is not rewritten into cheese bread. Local dish and brand names use Chinese names, descriptive names or transliteration; the separate original description remains available for verification.

Regenerate with `npm run foods:translate`; audit with `npm run foods:audit`. These commands need no translation service, API key or model download. An Argos English-to-Chinese 1.9 offline model was sampled during development, rejected for food-context errors, and is not used in the final catalog or generation process. Temporary evaluation files and runtime are removed after validation.

The audit checks exact ID coverage, source hash, untranslated Latin words and every original numeric qualifier, including repeated percentages and fractions. Approved Latin exceptions are vitamin letters, USDA dairy grade A, probiotic GG, V8/G2/XS/Z product codes and the source recipe code C-32. Current results: 13,225/13,225 coverage, zero unrecognized untranslated fragments, zero lost numeric qualifiers. The unchanged original `foods.json` SHA-256 is `781716e23b22e1e9ac4c24b6afc36947f10f6859c12a7e6e3f330f23e9e44e44`. Automated coverage is supplemented by food-family and context checks in `tests/food-translations.test.ts`, including rye versus triticale, kidney beans versus organs, egg white, whole milk, tea, no-added-sugar, free-range meat and ingredient lists. Coverage checks alone do not prove semantic accuracy; new or changed terms require contextual review and regression fixtures.

`lib/food-localization.ts` loads the full directory only on the server. Search results receive a complete `localizedName` alongside the 80-character saved label. Reading records and the recycle bin derives the same name only when source ID and original description agree. Writes discard this derived field; saved weights, manually corrected nutrients, names, timestamps and raw exports remain unchanged. Chinese search supports the complete translated vocabulary and preserves negated qualifiers as phrases. Bread searches retain word boundaries so sweetbreads, breaded meat and fryers are not mistaken for bread or rye.

Terminology references: [Cambridge's pumpernickel definition](https://dictionary.cambridge.org/dictionary/english-chinese-simplified/pumpernickel) for coarse rye bread; [Colonial Williamsburg's Spoon Bread recipe](https://www.colonialwilliamsburg.org/discover/resource-hub/recipes/spoon-bread/) for the soft cornmeal-based dish rendered descriptively as 玉米布丁式面包. These references inform names only, never nutritional values.

Further context references: [Cambridge's lentil translation](https://dictionary.cambridge.org/dictionary/chinese-simplified-english/%E5%B0%8F%E6%89%81%E8%B1%86) for 小扁豆; [Cambridge's cream of tartar definition](https://dictionary.cambridge.org/dictionary/english-chinese-simplified/cream-of-tartar) for 酒石酸氢钾; [NOAA's Chinook salmon description](https://www.fisheries.noaa.gov/species/chinook-salmon) for the king/Chinook synonym. They resolve terminology only and are not the source of the nutrition data.
