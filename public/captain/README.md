# Captain

原创彩色 3D 小队长：友善的短发面孔、深蓝运动服、白色星形胸章、红色手套与鞋部点缀、自然暖肤色和深棕头发。表达可靠、亲自示范、一起照顾身体的陪伴感。没有使用或修改第三方角色图片，也没有安装到 Codex。

## 网页资源

`manifest.json` 是网页消费入口。所有动作都是横向排列、透明背景的真实生成逐帧图片，每格 **192 × 208**。`durations` 单位是毫秒，逐项对应帧索引。可将背景宽度设为 `frames × 100%`，以帧索引选取背景位置。

| 文件 | 帧数 | 动作 |
| --- | ---: | --- |
| `avatar.png` | 静态 | 用于聊天联系人头像 |
| `idle.webp` | 6 | 双手扶腰、呼吸与眨眼 |
| `greeting.webp` | 4 | 抬手、挥手、回落 |
| `thinking.webp` | 6 | 手托下巴、眼神与表情变化 |
| `fitness.webp` | 6 | 手持双哑铃弯举 |
| `eating.webp` | 6 | 端碗、舀食、吃一口 |
| `rest.webp` | 6 | 盘腿休息、呼吸与眼睑变化 |

减少动态效果时使用该动作第一帧；联系人头像始终静态。动作只描述 Captain 自己，不表示使用者完成了训练或饮食记录。

## 来源与生成方法

2026-09-09 使用内置 ImageGen 生成初版灰色角色，并按用户要求将现有头像与六种网页动作着色。彩色版以原动作条为编辑目标，保留同一角色、原姿态/表情顺序、帧数和播放时长。`PROMPTS.md` 保存完整提示词集。先生成唯一角色基准图，之后每行动作均附带该基准图和仅供布局参考的间距图；没有用 CSS 移动、旋转或缩放同一张静态图来伪造动作。

使用 hatch-pet 的确定性脚本分离完整角色、归一化到固定帧格、组装图集、去除色键和检查透明边缘。每行独立检查帧数、全身完整性、身份、动作语义和配色。彩色编辑产生的外部留白按色键范围裁去，再登记回原帧格；没有用形变伪造动作。静态头像沿用 idle 第一帧的原头肩裁切。盘腿休息行在提取后统一缩小到 0.80 倍，使头部大小与站立形象一致，六个真实姿势保持不变。

`spritesheet.webp` 与 `pet.json` 保留为旧版灰色 v2 图集包，本轮未改色，网页不会加载它们：8 列 × 11 行、1536 × 2288，含九组标准动作和十六个顺时针注视方向。网页只加载六种独立动作条，不依赖附包。旧灰色图集的既有验收记录保留；当前网页使用上表的彩色独立动作条。

生成过程只涉及公开角色素材，没有读取或上传个人健康记录、对话、批注或凭据。
